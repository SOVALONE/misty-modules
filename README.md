# Модулі для Місті

Розширення («моди») для помічниці Місті та її сестер. Їх встановлюють у застосунку: **Налаштування → Модулі → Магазин**,
а в **Бібліотеці** вмикають і вимикають.

| Модуль | Що вміє | Автор |
|---|---|---|
| [📷 Живий перекладач з камери](modules/live-camera-translate) | Переклад тексту поверх камери, без інтернету | SOVALONE |

## Як влаштований модуль

Кожен модуль — окрема тека `modules/<id>/`:

```
modules/<id>/
├─ module.json   опис: назва, опис, автор, версія, дозволи, функції
├─ main.js       скрипт із функціями
└─ README.md     опис для людей
```

### module.json

```json
{
  "id": "my-module",                  // малі латинські літери, цифри, дефіс; = назва теки
  "name": "Назва",
  "description": "Що робить модуль",
  "author": "Хто зробив",
  "version": "1.0.0",                 // піднімайте при кожній зміні: так помічниці побачать оновлення
  "minApp": "1.7.2",                  // мінімальна версія помічниці
  "icon": "🧩",
  "permissions": ["camera"],          // camera, translate, notify, speak
  "words": "слово|інше слово",        // регулярка: коли давати моделі функції модуля
  "prompt": "Правило для помічниці, поки модуль увімкнено",
  "tools": [
    { "name": "my_tool", "description": "Коли і для чого кликати",
      "params": { "x": { "type": "string", "description": "…" } } }
  ],
  "script": "main.js"
}
```

### main.js

```js
var tools = {
  my_tool: function (args) {
    // повертає текст, який побачить помічниця
    return "Зроблено: " + args.x;
  }
};
```

Скрипт виконується в пісочниці: **немає доступу до Java, файлів телефона чи мережі**. Доступний лише об'єкт `misty`:

| Виклик | Дозвіл | Що робить |
|---|---|---|
| `misty.log(text)` | — | запис у журнал |
| `misty.language()` | — | мова користувача («uk») |
| `misty.storage.get(key)` / `set(key, value)` | — | маленьке сховище лише цього модуля |
| `misty.camera.liveTranslate({ to })` | `camera` | живий переклад з камери |
| `misty.notify(title, text)` | `notify` | сповіщення |
| `misty.say(text)` | `speak` | сказати вголос |

Виконання скрипту обмежене кількома секундами.

## Як додати модуль

1. Створіть теку `modules/<id>/` з `module.json`, `main.js`, `README.md`.
2. Допишіть модуль у `index.json` (з тією ж версією).
3. Закомітьте: магазин бере файли прямо з гілки `main`.
