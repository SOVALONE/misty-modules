# 🎓 Репетиторка мов

**Автор:** SOVALONE · **Вбудований** (є в Місті та сестрах з версії 1.7.2)

«Давай вчитись» — урок іноземною мовою: розмова, виправлення помилок, окуляри й указка.

Код модуля — у самому застосунку, а з'являється він після встановлення: **Налаштування → Модулі → Магазин → Встановити** (нічого не завантажується). Потім його вмикають, вимикають чи видаляють у **Бібліотеці**. Вимкнений модуль повністю зникає: помічниця не знає про його функції, а його фонова робота зупиняється.

**Функції для помічниці:** `tutor_mode`
