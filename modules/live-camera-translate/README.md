# 📷 Живий перекладач з камери

**Автор:** SOVALONE · **Версія:** 1.0.0 · **Потрібно:** Місті (чи сестра) 1.7.2+

Наведіть камеру на вивіску, меню, етикетку чи сторінку, і переклад з'явиться прямо поверх тексту, як у Google Lens.

- Скажіть: «переклади вивіску», «наведи камеру й переклади меню англійською», «що тут написано?»
- Мову перекладу можна змінити кнопкою 🌐 вгорі. «⏸ Зафіксувати» зупиняє кадр, щоб спокійно прочитати.
- Розпізнавання й переклад працюють **на телефоні** (Google ML Kit). Інтернет потрібен лише першого разу, щоб завантажити мовний пакет (~30 МБ на пару мов).
- Розпізнає латиницю (англійська, чеська, німецька, польська, французька…). Кирилицю розпізнавач ML Kit поки не читає.

**Дозволи:** камера.
