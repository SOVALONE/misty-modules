# 🌐 Переклад екрана й суфлер

**Автор:** SOVALONE · **Вбудований** (є в Місті та сестрах з версії 1.7.2)

Перекладаю все, що на екрані, і перекладаю розмову з іноземцем наживо.

Код модуля — у самому застосунку, тож встановлювати нічого не треба: його вмикають і вимикають у **Налаштування → Модулі → Бібліотека**. Вимкнений модуль повністю зникає: помічниця не знає про його функції, а його фонова робота зупиняється.

**Функції для помічниці:** `start_interpreter`, `translate_screen`
