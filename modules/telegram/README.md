# ✈️ Telegram і автопілот

**Автор:** SOVALONE · **Вбудований** (є в Місті та сестрах з версії 1.7.2)

Пишу й читаю Telegram від вашого імені, автопілот відповідає обраним контактам, голосові повідомлення.

> ⚠️ Без нього не працюватиме пошта з друзями й родиною (вона йде через Telegram).

Код модуля — у самому застосунку, тож встановлювати нічого не треба: його вмикають і вимикають у **Налаштування → Модулі → Бібліотека**. Вимкнений модуль повністю зникає: помічниця не знає про його функції, а його фонова робота зупиняється.

**Функції для помічниці:** `read_telegram`, `send_telegram_message`, `send_voice_message`, `telegram_autopilot`, `telegram_autopilot_report`
