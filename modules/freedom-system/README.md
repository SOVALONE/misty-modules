# 🕊️ Freedom System (БЕТА)

**Автор:** sovalo · **Вбудований** (є лише в Місті з версії 1.7.5) · **Бета**: типово вимкнений, вмикається в бібліотеці

Бета. Голос без Gemini: говорю локальною моделлю HolosTTS прямо на телефоні, без інтернету й без лімітів. Модель (~330 МБ) завантажується один раз. Не вийшло — говорю голосом Gemini, як раніше.

Код модуля — у самому застосунку, тож встановлювати нічого не треба: його вмикають і вимикають у **Налаштування → Модулі → Бібліотека**. Вимкнений модуль повністю зникає: помічниця не знає про його функції, а його фонова робота зупиняється.

Окремих функцій для помічниці не додає.

## Як це працює

- **Голос:** [HolosTTS](https://huggingface.co/patriotyk/HolosTTS) (Serhiy Stetskovych, MIT), збірка ONNX INT8, рахує процесор телефона (ONNX Runtime).
- **Наголоси:** словник [ukrainian-word-stress](https://github.com/patriotyk/ukrainian-word-stress) (2,9 млн словоформ, MIT), перетворений для телефона
  (`stress.bin.gz` у релізі `freedom-system-data-1` цього репозиторію; скрипт `scripts/freedom/build_stress_dict.py` у Місті).
- **Транскрипція:** [ipa-uk](https://github.com/patriotyk/ipa-uk) (MIT), перенесено на Kotlin; вивід збігається з оригіналом на 4000 словах.
- Модель (~330 МБ) завантажується один раз у **Налаштування → Модулі → Freedom System**. Там же голос (27, жіночі першими), швидкість і «Послухати».
- Не вийшло локально — помічниця говорить голосом Gemini, як без модуля. Вимкнули модуль — усе як раніше.

> Автор HolosTTS узяв голоси моделі з відкритих записів без згоди їхніх власників. Тож лише для особистого вжитку.
